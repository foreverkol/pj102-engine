# pj102 知识库引擎 · 朋友电脑完整安装指引（WorkBuddy + Obsidian）

> **本文目标**：在一台全新的 Windows 电脑上，从零装好 WorkBuddy 与 Obsidian，
> 把知识库引擎跑起来，生成你自己的 wiki，**一次性成功**。
> 按顺序做，每一步都有"预期看到什么"和"出问题怎么办"。
> 全程约 40-60 分钟（大部分是等下载安装）。

---

## 0. 开始前的检查清单

| 检查项 | 要求 |
|---|---|
| 电脑 | Windows 10/11，能上网 |
| 磁盘 | 任意盘剩余空间 ≥ 2GB |
| 你已收到 | `pj102-green-v2.1.1.zip`（约 615KB 压缩包，从本项目 GitHub 仓库的 **Releases** 页下载，也可由他人经微信/网盘转发） |
| 手机/邮箱 | 用于注册 WorkBuddy 和 MiniMax 账号 |

> **重要提示**：安装路径避免中文和空格（如用 `D:\pj102`，不要用 `D:\我的软件`），
> 可大幅降低出问题概率。

---

## 1. 安装 Python（引擎的运行底座，约 5 分钟）

引擎需要 Python 3.10 及以上。**先装它，再装别的。**

**方法 A（推荐，一行命令）**：
1. 按 `Win` 键 → 输入 `powershell` → 回车打开（蓝色窗口）
2. 复制粘贴这行命令，回车：
   ```
   winget install -e --id Python.Python.3.12
   ```
3. 装完后**关闭 PowerShell，重新打开一个**，输入 `python --version` 回车
4. ✅ **预期看到**：`Python 3.12.x`

**方法 B（winget 报错时用）**：
1. 浏览器打开 `https://www.python.org/downloads/`
2. 点黄色大按钮下载，运行安装包
3. ⚠️ **第一个界面务必勾选底部的 `Add python.exe to PATH`**，再点 Install Now
4. 验证方法同上

| 出问题怎么办 | 处置 |
|---|---|
| `python` 不是内部或外部命令 | 装完没重开 PowerShell，或没勾 Add to PATH → 重装一次（方法 B） |
| winget 提示找不到命令 | 系统太旧，用方法 B |

---

## 2. 安装 WorkBuddy（约 5 分钟）

1. 从 WorkBuddy 官网下载 Windows 安装包，双击安装（一路默认/下一步）
2. 首次启动，用手机号或微信注册并登录
3. ✅ **预期看到**：进入 WorkBuddy 主界面（左侧有会话/项目等导航）

---

## 3. 在 WorkBuddy 里创建本项目专属的独立项目（约 2 分钟）

知识库相关的一切对话都放在这个独立项目里，与朋友的其他事项互不干扰：

1. 在 WorkBuddy 里找到**新建项目**入口（首页或左侧项目列表的"+"，以你安装的界面实际位置为准）
2. 项目名称建议：**我的知识库**（随意，能认出来即可）
3. 创建完成后**进入该项目**，随便发一句"你好"确认会话正常
4. ✅ **预期看到**：项目出现在你的项目列表里，进去后可以正常对话

> 之后所有知识库操作，都在这个项目里对话完成。

---

## 4. 安装知识库引擎绿色包（约 5 分钟）

1. 把下载/收到的 `pj102-green-v2.1.1.zip` 解压到一个**纯英文路径**，
   推荐 `D:\pj102`（解压后里面有一个 `install.bat`）
2. 双击 `install.bat`
3. ✅ **预期看到**（按顺序）：
   ```
   [1/4] Python found: ...
   [2/4] venv created.
   [3/4] Engine installed. Smoke test:
   pj102-engine 2.1.0-dist
   ================================================
     Install complete!
   ```
4. 若 Windows/杀毒软件弹出提示，选择**允许/信任**（这是它在本机创建的隔离运行环境，无风险）

| 出问题怎么办 | 处置 |
|---|---|
| 提示 Python 3.10+ not found | 回到第 1 步装 Python（或重开一次命令行再试；装完 Python 后建议**重启电脑**让环境变量生效） |
| 窗口一闪就关，看不出结果 | 在包文件夹里点空白处，按住 Shift 右键 →"在此处打开 PowerShell"，手动输入 `.\install.bat` 看完整过程 |
| Offline install failed | 它会自动转在线安装，需要联网，等它跑完即可 |
| 提示 pj102_engine wheel not found | 解压不完整——删掉整个文件夹重新解压一次 |

**安装成功与否的快速校验（不看窗口也能确认）**：包文件夹里出现 `venv` 文件夹 = 引擎装好了；`C:\Users\你的用户名\pj102-kb` 文件夹出现 = 配置就绪；WorkBuddy 连接器管理里出现 `pj102-kb` = 注册完成。

**保底方案：手动安装（install.bat 走不通时，效果完全等价）**

在**包文件夹内**（必须是有 `whl` 文件夹的那一层！提示符路径显示错误位置就会报"file does not exist"）按住 Shift 右键空白处 →"在此处打开 PowerShell"，逐行执行：

```
py -3 -m venv venv
```
```
.\venv\Scripts\python.exe -m pip install --no-index --find-links whl .\whl\pj102_engine-2.1.0-py3-none-any.whl PyYAML
```
```
.\venv\Scripts\python.exe tools\register_mcp.py
```
```
.\venv\Scripts\pj102.exe version
```

最后一行显示 `pj102-engine 2.1.0-dist` 即安装完成。

> ⚠️ 注意：第 2 行必须用**完整文件名**（如上所示），不要写 `pj102_engine-*.whl` 带星号——PowerShell 不会把星号展开成真实文件名，会报"is not a valid wheel filename"。

---

## 5. 信任知识库工具（让 WorkBuddy 能查询你的 wiki，约 2 分钟）

`install.bat` 已自动把三个知识库工具（查询/巡检/统计）注册进 WorkBuddy，只需手动信任一次：

1. 打开 WorkBuddy → 进入**连接器管理**（设置/插件入口，以界面实际为准）
2. 在**自定义连接器**列表里找到 **`pj102-kb`**
3. 点击**信任 / Trust**
4. ✅ **预期看到**：`pj102-kb` 显示为已启用/已信任状态

> 没找到 `pj102-kb`？重启一次 WorkBuddy 再看；仍没有就在项目里对 agent 说
> "帮我检查 mcp.json 里的 pj102-kb 注册"。

---

## 6.（推荐）安装"安装向导"技能（约 2 分钟）

绿色包里自带一个给 agent 用的安装向导，装上后你只需说一句话：

1. 打开文件管理器，进入 `C:\Users\你的用户名\.workbuddy\skills\`
   （没有 `skills` 文件夹就新建一个）
2. 把绿色包里的 `skills\pj102-installer` 整个文件夹复制进去
3. 重启 WorkBuddy（或新开一个会话）
4. ✅ **预期看到**：对 agent 说"安装 pj102"时，它知道该做什么

> 这一步是可选的加速项；不装也不影响，下一步直接让 agent 读 SETUP_AGENT.md 即可。

---

## 7. 让 agent 完成部署配置（约 10 分钟，含申请 API key）

进入第 3 步创建的"我的知识库"项目，对 agent 说：

> **"按 D:\pj102\SETUP_AGENT.md 帮我完成部署"**
> （路径换成你的解压位置；若第 6 步装了技能，直接说"安装 pj102"也行）

agent 会依次问你几件事，如实回答即可：

| 它会问什么 | 你怎么答 |
|---|---|
| 源数据目录在哪 | 你打算存放录音转写文件的文件夹（如 `D:\我的转写`，没有就先建一个） |
| 核心人物是谁 | 对话里最重要的一两个人名 + 角色 |
| 关键词有哪些 | 你们常聊的 3-8 个业务话题词 |
| API key | 见下方申请流程 |

**MiniMax API key 申请流程**（agent 一般会引导，这里提前说明）：
1. 浏览器打开 MiniMax 开放平台，注册/登录
2. 进入"API Keys"（接口密钥）页面 → 创建新密钥 → 复制
3. 把密钥发给 agent（或按它的指引粘贴），它只写入你电脑的
   `C:\Users\你的用户名\pj102-kb\.env`，**不会外传**

配置完成后 agent 会用包内**虚构示例**做一次冒烟测试
（预期 `total: 1, type1: 1`），然后自动把示例清掉——**全程不碰你的真实数据**。

---

## 8. 准备录音转写文件（约 5 分钟）

把你的录音转写 markdown 文件放进源目录。**文件命名规则**（影响自动分类）：

| 类型 | 命名格式 | 示例 |
|---|---|---|
| 多人会议/周会纪要 | `日期时间+中文标题+_原文.md` | `20260908_221948项目周会_原文.md` |
| 两人通话记录 | `人名@手机号_日期时间标题_原文.md` | `20260829_191607张三通话记录@业务沟通_原文.md` |

不匹配的文件也不会丢（按 unknown 正常处理），但按规则命名效果最好。

---

## 9. 首次运行管线，生成你自己的 wiki（约 10-30 分钟）

在项目里对 agent 说：**"帮我摄入并运行管线"**。

1. 摄入：报告扫描到多少文件、分类情况
2. 运行：13 步 AI 处理管线逐文件生成 wiki 页（会产生少量 API 费用，
   通常**几分钱一个文件**；agent 会先告诉你预估）
3. ✅ **预期看到**：agent 汇报"生成完成"，并给你看 `pj102 stats` 的页数统计

| 出问题怎么办 | 处置 |
|---|---|
| 中途报额度/频率错误(429) | 稍等片刻对 agent 说"继续跑"，已完成的文件会自动跳过（断点续跑） |
| 提示 source_dir 占位符 | 第 7 步配置没完成，让 agent 回去补 |

---

## 10. 安装 Obsidian 并打开你的 wiki（约 5 分钟）

Obsidian 是浏览知识库的最佳工具（免费、本地、支持双链与关系图）：

1. 浏览器打开 `https://obsidian.md` → Download for Windows → 安装（一路默认）
2. 首次启动，选择 **"Open folder as vault"（打开文件夹作为仓库）**
3. 选择文件夹：`C:\Users\你的用户名\pj102-kb\wiki`
4. 若弹出信任提示，选 **Trust author and enable plugins**（信任并启用）
5. ✅ **预期看到**：左侧出现你的 wiki 页面树
   （Meetings / Entities / Knowledge / Summaries / Queries 等分区）
6. 推荐体验：
   - 点开任意页面，正文里的 `[[链接]]` 可直接点击跳转
   - 左侧 **Graph View（关系图谱）** 可看实体关联全景
   - Settings → About → Language 可切换简体中文界面

> Obsidian 只是"浏览器"，不改动任何数据；卸载它你的知识库也毫发无损。

## 11. 日常使用速查

| 你想做 | 在哪做 | 怎么做 |
|---|---|---|
| 问知识库问题 | WorkBuddy（我的知识库项目） | 直接问，如"X 参与过哪些会议" |
| 新增录音文件 | 文件管理器 | 放入源目录 → 对 agent 说"摄入并运行" |
| 质量巡检 | WorkBuddy | "跑一次 lint" |
| 浏览/搜索 wiki | Obsidian | 打开 vault，Ctrl+P 快速搜索 |
| 看知识库规模 | WorkBuddy | "跑一次 stats" |

## 12. 卸载（如需要）

1. 删除绿色包文件夹（如 `D:\pj102`）
2. 删除 `C:\Users\你的用户名\pj102-kb`（你的知识库数据，删除前自行备份）
3. 让 agent 把 WorkBuddy 里的 `pj102-kb` 连接器移除
4. 控制面板卸载 Obsidian（可选）
零残留。
